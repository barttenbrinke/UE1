UNREAL (1998) ON PSP-2000 -- CONTROLS
=====================================

The PSP has one analog stick, so the layout follows the usual PSP shooter
convention: the stick moves, the face buttons look, triggers fire. Everything
below is an ini binding ([Engine.Input] in System/Unreal.ini) except the
Select shift layer, which lives in the SDL input driver.

MOVEMENT (analog stick)
  push / pull   move forward / backward
  left / right  strafe
  The nub drifts a little at rest; DeadZoneXYZ=0.2 in [NSDLDrv.NSDLClient].

LOOK (face buttons) -- the PSP shooter convention, by physical position
  Triangle      look up
  Cross         look down
  Square        turn left
  Circle        turn right
  Turn/look rates are the TurnLeft/TurnRight/LookUp/LookDown aliases in
  [Engine.Input] (Speed=150 turn, 100 look); change those to taste.

WEAPONS (triggers)
  R             fire
  L             alt-fire

D-PAD
  Up            jump
  Down          duck
  Left          previous weapon
  Right         next weapon

SYSTEM
  Start         menu (also confirms in menus)
  Select        translator (read messages) -- and the shift key below

SELECT SHIFT LAYER (hold Select, then press)
  Unreal has no "use" key: doors, lifts and switches trigger on touch or when
  shot. What it does have are inventory actions, and there is no spare button
  for them, so Select doubles as a shift key:
  Select + Up      use the selected inventory item (flashlight, jump boots,
                   force field, seeds, health...)
  Select + Left    previous inventory item
  Select + Right   next inventory item
  Select + Down    translator (same as a plain Select tap)
  A quick tap of Select on its own still opens the translator.

THE REVERSE LAYOUT (face buttons move, stick looks)
  To try it, in Unreal.ini set:
    Joy4=MoveForward  Joy1=MoveBackward  Joy3=StrafeLeft  Joy2=StrafeRight
    JoyX=Axis aTurn speed=0.5
    JoyY=Axis aLookUp speed=0.5        (inverted; -0.5 for normal)
  Speed 2 was far too twitchy on hardware; 0.5 was usable.

HOW THE PAD IS NUMBERED (for editing bindings)
  SDL's built-in PSP mapping, as the driver sees it:
    Joy1=Cross  Joy2=Circle  Joy3=Square  Joy4=Triangle
    Joy5=Select Joy7=Start   Joy10=L      Joy11=R
    JoyX/JoyY = stick        JoyPovUp/Down/Left/Right = D-pad
  The shift layer reports the D-pad as Joy14 (up) Joy6 (down) Joy15 (left) Joy16 (right)
  while Select is held.
